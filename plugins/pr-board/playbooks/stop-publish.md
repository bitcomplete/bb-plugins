## Stopping point: Publish
Push the branch (no force-push), then wait for CI on the final head and diagnose any red check. Reply on every review thread you addressed: name the fix commit and the check that verifies it. Post replies and resolve threads only through `gh api graphql` (`addPullRequestReviewThreadReply`, `resolveReviewThread`), and afterwards confirm that you have no pending (unsubmitted) review on the PR. Resolve a thread only when its finding is fixed or the reviewer's concern is fully answered; leave it open with a reply when something is still owed. Re-request review from anyone who requested changes or approved an older head (`gh pr edit ${number} --add-reviewer <login>`). Stop there: do NOT merge, even when everything is green.
