# Repo Dashboard

Open **Repo Dashboard** in the BB sidebar. Choose **Parsley Health**, **Bit Complete**, or **Cscc** (`ira-cscc` on GitHub), then use the week arrows to select a Monday–Sunday week in Eastern Time (ET). Week boundaries and daily bars adjust for daylight saving time. Hover over or focus a day in the organization chart to highlight that day across contributors. Select a day to limit contributor and repository event details to that day; weekly counts, Flow scores, and bars remain unchanged. Select it again or use **Clear day** to restore all details. Expand a contributor for repository counts, then expand a repository to inspect linked pull requests. The dashboard caches current-week results for up to 24 hours and completed-week results for 30 days, including across plugin reloads. Use **Refresh** to fetch fresh GitHub activity.

Opened, merged, and closed counts belong to the PR author. In progress counts authored PRs created within the 90 days before the snapshot that remain open at the selected week's end, including drafts. For the current week, it shows PRs open at fetch time. Expand the age strip to inspect age ranges and repository groups; the strip uses the historical week end or current fetch time. The 90-day in-progress trend shows the total, the absolute change from the previous week, and the percentage change in a tooltip. A zero previous total has no percentage baseline. In progress does not contribute to daily bars or activity totals. Reviewed counts distinct PRs per contributor per week, including reviews on older PRs. Repeat submissions by one reviewer on one PR count once, on the latest review day. Closed counts exclude merged PRs. Bot accounts and pending reviews do not count. The week note summarizes the busiest day and the in-progress change when the previous snapshot is available.

Flow equals opened + 2 × merged + 0.5 × distinct PRs reviewed − 0.25 × any increase in in-progress PRs from the previous week. Read it alongside the raw counts as an activity signal. The view loads the previous in-progress snapshot after the selected week's activity. Flow shows a dash if that snapshot is unavailable. The view displays an error when GitHub returns incomplete data. Historical in-progress counts can be inaccurate for PRs that close and reopen. PRs that age out of the rolling 90-day window can also lower the trend without closing.

Expand **Review connections** to see distinct reviewed PR contributions from reviewers to PR authors and the share with author data. Older cached activity can lack author metadata; use **Refresh** to fill it. **Week postcard** starts expanded with space above it. It previews and downloads a local SVG with weekly counts, average daily Flow per active contributor, a daily stem chart, and current-week and 90-day snapshot labels. The average includes contributors with PR activity, including closed PRs, and excludes contributors with only in-progress PRs. It applies the existing Flow formula to each contributor before averaging and shows the active cohort sizes. The current-week rate divides by elapsed Eastern Time calendar days; completed-week rates divide by seven. The prior rate always uses the full prior week's activity. For the current week, the separate opens, merges, and distinct contributor–PR review rows still compare through the saved fetch time with the same Eastern Time weekday and time in the previous week. The Flow rate uses the selected, previous, and two-weeks-ago in-progress snapshots. The in-progress change compares snapshots, including the previous week's end; it does not reconstruct a same-point backlog. The postcard checks saved prior-week activity and the Flow baseline without a GitHub request. If the prior week is missing, select **Load previous week** to fetch it. If the two-weeks-ago snapshot is missing, select **Load Flow baseline** to fetch it. If older cached reviews cannot establish the prior count at the cutoff, the review comparison shows as unavailable; select **Refresh previous week** to update the cache. Review connections and Week postcard remain scoped to the selected week when you select a day.
